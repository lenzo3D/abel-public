            Usage cap

            Optional. Set a daily and/or weekly limit in estimated usage (US dollars, worked out from the cost Claude Code reports; on a subscription it is a yardstick, not a bill). Abel warns you on Telegram at 80% and 100%. At 100% it pauses class chat summaries and date extraction; chat, Do it and the morning briefing keep working. Paused work resumes by itself when the day or week resets (Singapore time, weeks start Monday). Leave a limit empty for no cap.

            Model for each job

            The smaller model (haiku) is cheaper and fine for short summaries and picking dates out of chat. Course documents and the briefing default to sonnet. Chat default means whatever your Claude Code uses.

            Calls per day

            Every call Abel makes to Claude is counted. Chat, Do it and browser chat report real token counts; the briefing, class chat summary and date extraction are estimates (marked ~), about 4 characters per token. Checking POLITEMall, Teams and your calendar makes no Claude calls. Usage counts against your Claude plan limits.
